# Failure Prediction AI – Startup & Project Risk Analyzer
## Milestone 1

### Setup
1. Extract ZIP (or pull repository).
2. Install Python.
3. `python -m venv venv`
4. `venv\Scripts\activate` (Windows)
5. `pip install -r requirements.txt`
6. Create PostgreSQL database `ml_project` and run `database.sql`.
7. Update `password` in `database.py`.
8. `python app.py`
